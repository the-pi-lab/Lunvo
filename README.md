## 🤯 Why LUNVO?

Most LinkedIn AI tools are **expensive SaaS products** that use unauthorized browser extensions. This risks **permanent account bans**. 

**LUNVO is different.** It is a 100% open-source, BYOK (Bring Your Own Key) application that runs locally. It uses a **3-Agent AI Pipeline** to generate hyper-viral content without ever touching the unofficial LinkedIn API.

---

## 🌟 Futuristic Features

### 🧠 1. Universal AI Router (BYOK)
No vendor lock-in. Connect your favorite LLMs instantly:
- 🟢 **OpenAI** (GPT-4o, O1, GPT-3.5)
- 🟣 **Anthropic** (Claude 3.5 Sonnet)
- 🔵 **Google AI** (Gemini 1.5 Pro)
- 🟠 **Groq / Local LLMs** (via LM Studio / Ollama)

### 🤖 2. The 3-Agent Content Pipeline
Why use one prompt when you can have a team? LUNVO uses a native, strict orchestrator:
- **🕵️‍♂️ Scout Agent**: Finds trends and creates 3 distinct viral hooks (Data, Story, Controversial).
- **✍️ Writer Agent**: Drafts the post by strictly following your unique formatting and tone.
- **🧐 Critic Agent**: Audits the draft against the LinkedIn algorithm, removes fluff, fixes whitespace, and assigns a Virality Score (1-100).

### 🧬 3. Voice DNA Technology
Configure your **Voice DNA** with interactive sliders (Formality, Emoji Usage, Technical Depth, Snark Level). LUNVO saves this schema locally and dynamically injects it into every prompt so the AI sounds exactly like **YOU**.

### 🔄 4. Multi-Channel Repurposer Studio
Turn a single LinkedIn post into a multi-channel empire with one click:
- 🐦 **Twitter Thread**: Automatically numbered and hook-optimized.
- 💌 **Newsletter / Blog**: Expanded long-form deep dive.
- 🎥 **Video Script**: 60-second visual/audio script for TikTok & Reels.

## ⚡ Getting Started (Zero to Hero in 2 mins)

### Prerequisites
- Node.js (v18+)
- At least one API Key (OpenAI, Anthropic, Gemini, or Groq)

### 🚀 Installation

```bash
# 1. Clone the repository
git clone https://github.com/the-pi-lab/Lunvo.git
cd Lunvo

# 2. Install dependencies
npm install

# 3. Setup Environment
# Create a .env.local file and add your Supabase config (optional for cloud sync)
echo "NEXT_PUBLIC_SUPABASE_URL=your_url" > .env.local
echo "NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key" >> .env.local

# 4. Start the Engine
npm run dev
```

Navigate to `http://localhost:3000` and start dominating LinkedIn!
